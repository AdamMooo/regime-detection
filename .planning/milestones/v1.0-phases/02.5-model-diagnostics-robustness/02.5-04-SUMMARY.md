### Task 3: Update signals.py ✅
**Files:** signals.py (180 lines added/modified)

Augmented signal output with GARCH VaR and risk warnings:
- **New function: `compute_garch_var(regime_name, recent_returns, alpha=0.05)`**
  - Fits GARCH(1,1) on recent returns
  - Returns dynamic VaR: -z_crit * σ_t (negative for loss)
  - Falls back gracefully on small samples
- **New function: `varhhmm_warning(garch_var, regime_prob, regime_changed_today)`**
  - Returns warning message if VaR < -3%, regime prob < 0.6%, or regime shift detected
  - Used to alert traders to elevated risk conditions
- **New function: `validate_signal_schema(signal)`**
  - Validates required fields: current_regime, bot_label, date, garch_var_95
  - Validates bot_label is one of [LOW_VOL, MED_VOL, HIGH_VOL]
  - Validates garch_var_95 in range [-1.0, 0.0]
  - Raises ValueError if invalid
- **Updated `compute_signals()` function:**
  - Added parameter: `include_garch_var=True`
  - Computes GARCH VaR from recent returns
  - Generates risk warning if conditions warrant
  - Returns signal dict with new fields: `garch_var_95`, `warning`
  - Validates signal before returning
  - Updated docstring with Phase 2.5.4 details
