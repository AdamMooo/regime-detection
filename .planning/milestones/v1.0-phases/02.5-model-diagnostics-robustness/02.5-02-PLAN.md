## Key Facts

**Problem:** 7 features selected on full dataset (2010–2026), creating implicit lookahead bias. Features may be overfitted to the entire history, not generalizable to future OOS data.

**Solution:** 
1. Train set: 2010–2020 (first 2520 trading days)
2. Test set: 2021–2026 (held-out, never used for selection)
3. Select best features on train set only
4. Evaluate both original (7 features) and newly selected features on test set
5. Compare: regime accuracy, VaR metrics, regime stability
6. Decision: keep original or switch to new features

**Causality:** All feature engineering uses expanding windows (past data only), no future data leaks.
</context>
