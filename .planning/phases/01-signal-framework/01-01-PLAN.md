signal-spec template and the validation-standards document. This is a documentation/specification plan — no
code, no signal, no data pipeline.

fills in one consistent standard instead of inventing its own, and so the assumption ledger stays consistent.

Decisions covered: D-04, D-05 (template); D-01, D-02, D-03, D-07 (governing invariants); D-10, D-12 (research-
integrity rules in the standards doc).
</objective>

the HARD BOUNDARY content audit (project CLAUDE.md): the market-understanding layer names market assumptions
and STOPS. The produced docs must contain NONE of these as an output field, confidence definition, ledger
status, or instruction: portfolio · allocation · exposure · weight · sleeve · tilt · cash · buy · sell ·
risk-on · risk-off · any composite/single-score phrasing. The tokens may appear ONLY inside explicit
prohibition / out-of-scope / boundary statements. The confidence dimension names must NOT copy the stale
"regime-relevance" / "portfolio-relevance guard" wording (that lives in 01-02, but the template's attribute-7
pointer must use "current-relevance"). Because prohibition text legitimately contains the forbidden tokens, the
audit is a reviewed grep (list every hit, confirm each is a prohibition), never a bare `== 0` gate.

    Create `.planning/framework/validation-standards.md` — the cross-signal law the template points at. Sections
    to write, each as an enforceable rule not aspiration: (a) Causal-only / point-in-time rule — trailing/forward
    filtering, no look-ahead, point-in-time reconstruction for revised macro series; (b) The mechanism gate — a
    signal needs a written structural reason (risk-premium or risk-management channel) it survives being known;
    novelty/backtest/literature alone are disqualifying as sole basis; (c) Confound-check requirement — every
    context stat must rule out its confound (cite the rate-cycle-confound and dispersion-lead precedents as
    illustration); (d) Out-of-hypothesis-sample confirmation — the descriptive property must replicate on the
    Japan/Europe panels before any SUPPORT claim, or a documented failure is recorded; (e) The temporal-freeze
    protocol — one look, prereg + overnight cooling-off + explicit dated sign-off; failure modes fixed before the
    validation run; deviations disclosed with a dated note, never silently edited; (f) A completeness checklist
    (TRIPOD-style) that must be fully answered — one checkbox per template attribute + each header field — gating
    the dated sign-off; (g) Template versioning discipline — semver the template, each signal records the version
    it filled, a signal never edits the template to fit itself; a genuine gap becomes a versioned amendment
    (MINOR additive / MAJOR breaking) applied uniformly with a changelog, prior signals note the version they
    were signed off against; (h) A dedicated HARD BOUNDARY content-audit subsection — the invariant that every
    document names market assumptions and STOPS, the explicit forbidden-vocabulary list (portfolio, allocation,
    exposure, weight, sleeve, tilt, cash, buy, sell, risk-on, risk-off, any composite/single-score phrasing), and
    the reviewed-grep audit procedure to run before sign-off (list every hit, confirm each is a prohibition, never
    a bare zero-count gate). Add (i) a named "No signal designed around a desired conclusion" integrity rule
    (D-10) — stated explicitly as its own rule, NOT left implicit in the mechanism-gate/prereg text: mechanism,
    metric, and validation are specified before results are interpreted, and a signal that only "works" because it
    was tuned toward a wanted answer is REJECTED. Add (j) a "Framework optimization target" statement (D-12) — the
    framework optimizes for research integrity, reproducibility, and understanding of market structure, explicitly
    NOT predictive accuracy and NOT decision usefulness; with the tie-breaker that where a design choice trades
    reproducibility/integrity against apparent usefulness, integrity wins. State D-01/D-02/D-03/D-07 as governing
    invariants at the top: market-state intelligence not prediction; no single score, no bullish/bearish answer,
    no implied action; the output is a multi-dimensional vector and disagreement between signals is preserved;
    signals are independent research modules and the framework must not induce a shared latent state.
  </action>
