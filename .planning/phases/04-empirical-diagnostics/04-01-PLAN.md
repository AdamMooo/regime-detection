# Phase 04 Plan 01: Empirical Diagnostics

## Objective

Measure regime quality before any changes by producing a diagnostics report covering:
vol ordering, dwell time, transition matrix, OOS vs persistence baseline, failure mode
analysis, and regime-conditional forward return analysis.

Pure measurement phase — no model changes, no feature changes, no pipeline changes.
