    1. `load_data()`:
       - Reads feature data and SPY market returns from `DATA_DIR` (use the same loading path as `scripts/analysis/select_k_via_crossval.py`). Returns `(market: pd.DataFrame, features: pd.DataFrame, spy_returns: pd.Series)`.

       - Exact run-length loop from `src/signals/signals.py:_validation_metrics` (see 06-PATTERNS.md). Works on any label Series (named or integer).

    3. `oos_accuracy(is_named_labels: pd.Series, oos_named_labels: pd.Series) -> tuple[float, int]`:
       - Intersects indices, compares named labels, returns `(accuracy, n_common)`. Pattern from `signals.py:_oos_validation`.

    4. `run_studenthmm_oos(market, features) -> dict`:
       - Calls `walk_forward(market, features, n_states=N_STATES)` (USE_HDP=False is already config default — the harness uses StudentTHMM).
       - Returns `{'oos_named_labels': series, 'name_map': dict, 'dwell': float, 'n_obs': int}`. Dwell is computed from returned OOS named labels.

    5. `run_hdp_oos(market, features, spy_returns) -> dict`:
       - Replicate the walk_forward fold loop manually so HDP sees the SAME `pcs` arrays on the SAME date ranges (Pitfall 1 alignment guard). Per fold:
         a. Standardize training slice via `expanding_standardize`; fit rolling PCA via `fit_rolling_pca` (same API `walk_forward` uses).
         b. Call `fit_hdp_hmm(pcs, K_max=HDP_TRUNCATION, inference='svi')` — LITERAL `inference='svi'`; do not allow a parameter or env override (D-02 lock).
         c. `diag = mcmc_diagnostics(result, samples)`. If `diag['converged']` is False, record `converged=False` for this fold and SKIP recording its labels (Pitfall 3 guard).
         d. `params = posterior_mean_params(samples, K_max=HDP_TRUNCATION)`; `labels, _, _, active_states = get_labels_and_probs(pcs, params)`; `name_map = label_regimes_hdp(labels, active_states, spy_returns)`.
         e. Map integer labels to named labels via `name_map`, slice the OOS portion of the fold, collect into a single concatenated OOS named-label series.
       - Returns `{'oos_named_labels': series, 'dwell': float, 'n_obs': int, 'all_folds_converged': bool, 'n_folds_converged': int, 'n_folds_total': int}`.

    6. `compare_and_verdict(student_metrics, hdp_metrics) -> dict`:
       - Compute `accuracy_delta = hdp_accuracy - student_accuracy` and `dwell_delta = hdp_dwell - student_dwell`.
       - If not all HDP folds converged: `verdict = 'inconclusive'`.
       - Else if `accuracy_delta >= 0.02` AND `dwell_delta > 0` AND `dwell_delta` is at least 10% of `student_dwell` (operationalizing "meaningfully longer" — D-03): `verdict = 'hdp_wins'`.
       - Else: `verdict = 'studenthmm_wins'`.
       - Returns dict with all numbers + verdict.

    7. `main()`:
       - Loads data, runs both paths, computes verdict, prints a formatted comparison table to stdout (match columns from 06-PATTERNS.md MODEL_CARD format: Metric | StudentTHMM | HDP-HMM (SVI) | Win threshold | Winner).

    HOWEVER — for IS accuracy: this comparison is OOS-only per D-01 and D-04 (same Phase 4/5 OOS split). Do NOT compute IS accuracy as a fallback metric. The "OOS accuracy" in the verdict uses the pattern: compare the named-label series from this model's OOS walk-forward to the named-label series from a FULL-SAMPLE fit of the same model (this is the `_oos_validation` definition in signals.py — IS full-sample labels vs OOS walk-forward labels, both named). Run a full-sample fit for each model to produce the IS baseline that OOS is compared against.
