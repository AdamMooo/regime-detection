<objective>
Plan 2 — Fix OOS label variant explosion (D-06, D-07).

The walk-forward validation in `src/core/orchestrator.py::walk_forward()` produces 8 distinct `regime_name_oos` values instead of the expected 3. The current code (lines 119–133) uses VIX-rank-per-fold to map fold-discovered states to regime names, but each fold's HMM discovers states in a different order, so the same name can map to different underlying states across folds — producing label proliferation.

Replace the broken VIX-rank-only mapping with **Hungarian matching** (`scipy.optimize.linear_sum_assignment`):
1. Compute IS reference name map via VIX-rank on the training-window labels (preserves ordinal Low/Med/High semantics).
2. Build an overlap (confusion) matrix between fold's raw_preds and the IS train_labels on the overlapping training-window slice.
3. Solve `linear_sum_assignment(-overlap)` to maximize overlap → injective fold→IS state mapping.
4. Apply that mapping to produce `regime_name_oos`.
5. Add a hard assertion at the end of `walk_forward()`: `assert n_distinct <= n_states` so any future fold-alignment regression fails loudly in CI.

Purpose: OOS evaluation only makes sense if every fold uses the SAME regime label vocabulary. Without alignment, any OOS metric (accuracy, dwell time, transition matrix) is meaningless.

Output: 1 modified source file + 1 new regression test file.

    # The previous VIX-rank-per-fold approach produced 8 distinct regime_name_oos
    # values because each fold's HMM discovers states in different order; ranking
    # by VIX did not enforce a one-to-one correspondence to in-sample state ids.

    vix_train = market['VIX'].reindex(train_feats_valid.index).values
    tl = train_labels[:len(vix_train)]

    # Build IS reference: VIX-rank name map for the training-window labels.
    # This preserves ordinal Low/Med/High semantics on the IS side.
    regime_vix = {}
    for r in range(n_states):
        mask = (tl == r)
        regime_vix[r] = float(np.nanmean(vix_train[mask])) if mask.sum() > 0 else 0.0
    is_sorted = sorted(regime_vix, key=lambda k: regime_vix[k])  # IS state ids, VIX-asc
    names = REGIME_NAMES.get(n_states, [f'Regime-{i}' for i in range(n_states)])
    is_name_map = {is_sorted[i]: names[i] for i in range(n_states)}

    # Hungarian alignment: cost matrix = -overlap between fold raw_preds and IS train_labels
    # on the overlapping training-window slice. Maximizing overlap = minimizing -overlap.
    raw_preds_arr = np.asarray(raw_preds)
    n_overlap = min(len(raw_preds_arr), len(tl))
    rp_slice = raw_preds_arr[:n_overlap]
    tl_slice = tl[:n_overlap]
    overlap = np.zeros((n_states, n_states), dtype=int)
    for i in range(n_states):
        for j in range(n_states):
            overlap[i, j] = int(((rp_slice == i) & (tl_slice == j)).sum())
    row_ind, col_ind = linear_sum_assignment(-overlap)  # maximize overlap
    # row_ind[k] = fold-state index; col_ind[k] = aligned IS-state index
    fold_name_map = {int(row_ind[k]): is_name_map[int(col_ind[k])] for k in range(n_states)}

    """Phase 9 Plan 2 regression tests — OOS label alignment fix (D-06, D-07).

    Verifies walk_forward() uses Hungarian matching to align fold-discovered states
    to in-sample regime names, producing at most K=3 distinct regime_name_oos values.
    """
    import numpy as np
    import pandas as pd
    import pytest
    from scipy.optimize import linear_sum_assignment

    from src.config import REGIME_NAMES


    class TestHungarianAlignment:
        """D-06: Hungarian matching produces injective fold->IS state mapping."""

        def test_hungarian_overlap_matrix_built_correctly(self):
            """Given two label arrays, Hungarian on -overlap maximizes total agreement."""
            n_states = 3
            # Fold predicts states (0, 1, 2) but they correspond to IS states (2, 0, 1)
            raw_preds = np.array([0, 0, 0, 1, 1, 1, 2, 2, 2] * 10)
            train_lab = np.array([2, 2, 2, 0, 0, 0, 1, 1, 1] * 10)
            overlap = np.zeros((n_states, n_states), dtype=int)
            for i in range(n_states):
                for j in range(n_states):
                    overlap[i, j] = int(((raw_preds == i) & (train_lab == j)).sum())
            row_ind, col_ind = linear_sum_assignment(-overlap)
            mapping = {int(row_ind[k]): int(col_ind[k]) for k in range(n_states)}
            assert mapping[0] == 2
            assert mapping[1] == 0
            assert mapping[2] == 1
            assert len(set(mapping.values())) == n_states  # injective


    class TestOOSLabelCountGuard:
        """D-07: regression assertion fires when fold alignment fails."""

        def test_assertion_logic_directly(self):
            """The assertion mechanism: more distinct names than n_states must fail."""
            n_states = 3
            bad_names = pd.Series(['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H'] * 5)
            n_distinct = int(bad_names.dropna().nunique())
            with pytest.raises(AssertionError):
                assert n_distinct <= n_states, f"too many: {n_distinct}"

        def test_canonical_names_only(self):
            """REGIME_NAMES[3] is a list of exactly 3 canonical name strings."""
            canonical = REGIME_NAMES[3]
            assert len(canonical) == 3
            assert all(isinstance(n, str) for n in canonical)

            from src.core.orchestrator import walk_forward
