<objective>
Plan 3 — Architectural root-cause fix for regime label unreliability.

## Why the old approach was wrong

The original Plan 3 proposed tuning VOL_BRACKETS thresholds. That would have been a cosmetic
patch. The actual root cause is a semantic mismatch with two stacked failures:

1. **VIX_BYPASS forces clustering on implied vol (VIX)** — the HMM groups days by VIX level,
   not realized vol. In 2021, VIX was elevated (~18) while realized vol was 13%. VIX-driven
   clustering assigns those days to the "high" state.

2. **Rank-based naming labels by ordinal position, not absolute meaning** — `label_regimes_hdp()`
   sorts states by their mean realized vol and names the highest-ranked state "High-Vol"
   regardless of its actual vol. In a sample where no state has high vol, the least-calm
   state still gets the "High-Vol" name. This is why a 13% realized-vol period gets labeled
   "High-Vol": it is merely the highest of three calm states.

These two failures compound: VIX drives the clustering into states that don't align with
realized vol, then rank naming assigns "High-Vol" to whatever state VIX pushed the most
days into.

## The fix

**Step 1 — Remove VIX_BYPASS.** Set `VIX_BYPASS = False` in config. The bypass already checks
a flag at three sites (orchestrator.py:100, train.py:2050, train.py:2350) — one config change
disables all three. VIX is already in FEATURE_SUBSET, so the model retains VIX signal through
PCA; we just stop double-counting it as a forced 6th dimension.

**Step 2 — Rewrite label_regimes_hdp() with absolute brackets.** Each state gets a name from
VOL_BRACKETS based strictly on where its mean annualized realized vol falls. If the state's
mean vol is 13%, it is "Low-Vol" or "Moderate-Vol" — whichever bracket 13% belongs to —
regardless of whether it is the highest state in the sample. If no state clears the
Elevated-Vol threshold, no state gets that label. That is the correct output.

**Step 3 — Retrain and discover state vols.** After code changes, run the full pipeline. The
training log prints per-state realized vols. A Task 3 checkpoint reviews these and confirms
whether VOL_BRACKETS thresholds need adjustment (if the new states land in unexpected ranges).

**Step 4 — Validate and add regression tests.** The hard guarantee: no state whose mean
realized vol is below the high-vol threshold can be named 'Elevated-Vol' or 'Crisis-Vol'.
One regression test locks this in permanently.

## Side effects and what they solve

- **OOS label explosion (Plan 09-02)** is automatically fixed. Absolute naming is independent
  per fold — each fold labels states by their absolute vol bracket, not by rank within that
  fold. A state with 13% realized vol is "Moderate-Vol" in fold 1 AND fold 2. No Hungarian
  matching needed. This is why 09-02 is closed.

- **IS / OOS distribution divergence** narrows. The IS model currently calls 55.9% of days
  High-Vol; OOS calls 22.8%. After absolute naming, both IS and OOS label by the same
  realized-vol thresholds, so they should converge.

- **lev_effect20** (F=0.4, p=0.70 — statistically indistinguishable from noise) is removed
  from FEATURE_SUBSET as part of the feature cleanup.

## Pseudocode for the rewritten label_regimes_hdp()

```python
def label_regimes_hdp(labels, active_states, spy_returns, vol_brackets=None):
    if vol_brackets is None:
        from src.config import VOL_BRACKETS
        vol_brackets = VOL_BRACKETS

    K_eff = len(active_states)

    # Compute annualized realized vol (%) for each state
    regime_vol = {}
    for i in range(K_eff):
        mask = (labels == i)
        regime_vol[i] = float(np.std(spy_returns[mask]) * np.sqrt(252) * 100) if mask.sum() > 5 else 0.0

    # Assign each state to the bracket its realized vol falls into (no rank)
    name_map = {}
    for i in range(K_eff):
        vol = regime_vol[i]
        assigned = vol_brackets[-1][2]          # default: top bracket (safe fallback)
        for low, high, bracket_name in vol_brackets:
            if low <= vol < high:
                assigned = bracket_name
                break
        name_map[i] = assigned

    return name_map, regime_vol   # return realized vols for audit logging
```

Key change: `vol_brackets[-1][2]` as fallback means a state with vol above all defined thresholds
gets the highest bracket name, never a lower one. The rank-based sort and REGIME_NAMES[K]
lookup are removed entirely.

Note: the function signature gains `regime_vol` in the return tuple. All callers that currently
do `name_map = label_regimes_hdp(...)` will need to be updated to
`name_map, state_vols = label_regimes_hdp(...)`. Grep for callers before writing.

## VOL_BRACKETS threshold note

The current brackets are (0–10, 10–18, 18–28, 28+). Based on the observed state vols from
the current model (8.6%, 11.8%, 18.8%), the 18% Elevated-Vol boundary is right at the edge
of the current High-Vol state. After removing VIX_BYPASS, the new model may discover states
with different realized vols — potentially a genuine crisis state at 22–28%. Task 3 exists
specifically to review what the retrained model discovers and confirm (or adjust) the
thresholds before writing the regression test. Do not pre-commit to final threshold numbers
in Task 1.

    ```python
    """Phase 9 Plan 3 regression tests — absolute vol-bracket labeling guarantee.

    These tests protect the core architectural invariant: regime labels must reflect
    absolute realized volatility, not rank within a sample. A state with genuinely low
    realized vol must never receive a high-vol label, regardless of what other states exist.

    This is the critical guard for algo-trading-bot sizing semantics: HIGH_VOL suppresses
    new entries and halves position size. Mislabeling calm periods as HIGH_VOL corrupts
    every risk decision the bot makes.
    """

        def test_no_state_below_threshold_named_high_vol(self):
    ```

    ```python
    """
    Regime label audit — per-day transparency report.

    Prints a table showing, for every day in regime_results.csv:
      date | regime_name | state_mean_vol | day_realized_vol_10d | label_correct

    'label_correct' is True if the day's 10-day trailing realized vol bracket
    matches the assigned regime_name. This is the ground-truth check: can you
    look at any labeled day and immediately verify the label makes sense?

    Run: python scripts/analysis/regime_label_audit.py [--tail N] [--high-vol-only]
    """
    import argparse
    import numpy as np
    import pandas as pd
    import sys
    import os
    from src.config import DATA_DIR, VOL_BRACKETS

    HIGH_VOL_NAMES = {'Elevated-Vol', 'Crisis-Vol'}


    def bracket_for_vol(vol_pct):
        """Return the bracket name for an annualized vol percentage."""
        for low, high, name in VOL_BRACKETS:
            if low <= vol_pct < high:
                return name
        return VOL_BRACKETS[-1][2]


    def regime_label_audit(tail=None, high_vol_only=False):
        df = pd.read_csv(os.path.join(DATA_DIR, 'regime_results.csv'),
                         index_col=0, parse_dates=True)
        feat = pd.read_csv(os.path.join(DATA_DIR, 'features_transformed.csv'),
                           index_col=0, parse_dates=True)

        common = df.index.intersection(feat.index)
        spy_ret = feat.loc[common, 'SPY_ret']

        # 10-day trailing realized vol (annualized %)
        rv10 = spy_ret.rolling(10).std() * np.sqrt(252) * 100

        # Per-regime state mean vol from the IS labels
        regime_col = 'regime_name'
        merged = df[[regime_col]].join(rv10.rename('rv10'), how='inner').dropna()

        state_mean_vols = (
            merged.groupby(regime_col)['rv10'].mean().round(1).to_dict()
        )

        rows = []
        for date, row in merged.iterrows():
            name = row[regime_col]
            day_rv = row['rv10']
            state_mv = state_mean_vols.get(name, 0.0)
            expected_bracket = bracket_for_vol(state_mv)
            correct = (expected_bracket == name)
            if high_vol_only and name not in HIGH_VOL_NAMES:
                continue
            rows.append({
                'date': date.date(),
                'regime_name': name,
                'state_mean_vol_%': round(state_mv, 1),
                'day_rv10_%': round(day_rv, 1),
                'expected_bracket': expected_bracket,
                'label_ok': '✓' if correct else '✗ MISMATCH',
            })

        result = pd.DataFrame(rows)
        if tail:
            result = result.tail(tail)

        print(result.to_string(index=False))
        print()
        mismatches = (result['label_ok'] != '✓').sum()
        print(f"Total rows: {len(result)}  |  Mismatches: {mismatches}")
        if mismatches > 0:
            print("WARNING: mismatches exist — state mean vol crosses a bracket boundary.")
        return result


    if __name__ == '__main__':
        parser = argparse.ArgumentParser()
        parser.add_argument('--tail', type=int, default=None,
                            help='Show only the last N rows')
        parser.add_argument('--high-vol-only', action='store_true',
                            help='Show only High-Vol labeled days')
        args = parser.parse_args()
        regime_label_audit(tail=args.tail, high_vol_only=args.high_vol_only)
    ```
